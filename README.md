# 📸 Photography Booking Website

A clean and modern photography portfolio and booking platform built for showcasing photography packages and allowing users to book sessions with ease.

---

## ✨ Features

- 📦 Display of photography packages with:
  - Title
  - Description
  - Price
  - High-quality image
- 📅 Booking form for scheduling photography sessions
- 🧾 Dummy booking data or connected backend
- 📱 Fully responsive and user-friendly design
